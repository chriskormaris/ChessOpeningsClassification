Project

Chess Openings Classifier is a lightweight web app that predicts common chess openings from board images. It uses a trained model to analyze piece placement and return the most likely opening (for example: Ruy Lopez, Italian Game, Queen's Gambit, Sicilian Defense).

Usage tips
  • Images can be either grayscale or RGB.
  • Upload clear board screenshots showing the full board.
  • Prefer images where pieces are distinguishable and lighting is uniform.
